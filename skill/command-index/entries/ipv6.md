# `ipv6` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `ipv6 local-prefix` — changes settings

Configures local IPv6 ULA prefixes either from a literal prefix or from an automatically generated default.

**RCI** `/rci/ipv6/local-prefix`

**Arguments:**

| Argument | Notes |
|---|---|
| `default` | Requests a persistent unique prefix generated by the router. |
| `prefix` | Literal ULA prefix in `fd00::/8`, with a prefix length no longer than /48. |

**Catch:** `default` enables the generated-prefix setting, while the example treats a literal prefix as a separately added static prefix; the two forms are not interchangeable.

### `ipv6 name-server` — changes settings

Configures static IPv6 DNS server entries, optionally scoped by domain and interface.

**RCI** `/rci/ipv6/name-server`

**Arguments:**

| Argument | Notes |
|---|---|
| `address` | DNS server IPv6 address. |
| `domain` | Domain matched by the DNS proxy; `""` denotes the default domain. |
| `interface` | Interface on which the server entry is configured. |

**Catch:** `""` is a sentinel for the default domain, and repeated commands add multiple static server entries rather than replacing one value.

**Blast radius:** bare `no ipv6 name-server` clears the entire static IPv6 DNS-server list; an argument-bearing form removes the specified entry from the static and active lists.

### `ipv6 pass` — changes settings

Configures IPv6 Pass Through between a WAN interface and a LAN interface.

**RCI** `/rci/ipv6/pass`

**Arguments:**

| Argument | Notes |
|---|---|
| `wan-iface` | WAN interface name or alias. |
| `lan-iface` | LAN interface name or alias. |

**Catch:** the example shows aliases being resolved to full interface names in the confirmation, so a client should not assume the response echoes the supplied aliases.

### `ipv6 route` — changes settings

Adds a static IPv6 route through an interface or gateway.

**RCI** `/rci/ipv6/route`

**Arguments:**

| Argument | Notes |
|---|---|
| `prefix` | Destination IPv6 prefix. |
| `default` | Keyword selecting the default route. |
| `interface` | Interface used by the route; the syntax permits an optional gateway after it. |
| `gateway` | Router address on a directly connected network; it can also be supplied as the sole next-hop form. |

**Catch:** the grammar has two distinct next-hop forms—an interface with an optional gateway, or a gateway without an interface—and `default` is a route sentinel rather than a literal IPv6 prefix.

### `ipv6 static` — changes settings

Creates an IPv6 firewall rule allowing inbound traffic to a registered home-network device.

**RCI** `/rci/ipv6/static`

**Arguments:**

| Argument | Notes |
|---|---|
| `protocol` | `tcp`, `udp`, `tcpudp`, or `icmp6`. |
| `interface` | Input interface name or alias. |
| `mac` | MAC address of the target host. |
| `port` | TCP/UDP destination port. |
| `end-port` | Upper end of a TCP/UDP port range. |

**Catch:** the argument list documents the ICMPv6 choice as `icmp6`, but the example invokes `icmpv6`; the block does not clarify whether that spelling difference is accepted.

### `ipv6 subnet` — changes settings

Selects a LAN IPv6 subnet configuration context, creating the segment if it does not exist.

**RCI** `/rci/ipv6/subnet`

**Arguments:**

| Argument | Notes |
|---|---|
| `name` | Subnet name or alias. |

**Catch:** entering an unknown subnet name attempts to create a new segment rather than reporting only a lookup failure.

### `ipv6 subnet bind` — changes settings

Binds the current IPv6 subnet to an interface.

**RCI** `/rci/ipv6/subnet/bind`

**Arguments:**

| Argument | Notes |
|---|---|
| `bind` | Interface name or alias to bind to the subnet. |

**Catch:** NONE

### `ipv6 subnet dns-server` — changes settings

Configures the name servers advertised for the current IPv6 subnet.

**RCI** `/rci/ipv6/subnet/dns-server`

**Arguments:**

| Argument | Notes |
|---|---|
| `address1` | Primary IPv6 DNS-server address. |
| `address2` | Optional secondary IPv6 DNS-server address. |
| `disable` | Alternative that disables name-server use for the subnet. |

**Catch:** `disable` is a mutually exclusive alternative to the address form, while `no dns-server` clears the configured name-server setting.

### `ipv6 subnet mode` — changes settings

Selects DHCPv6 or SLAAC address configuration for hosts in the current subnet.

**RCI** `/rci/ipv6/subnet/mode`

**Arguments:**

| Argument | Notes |
|---|---|
| `mode` | `slaac` enables stateless autoconfiguration; `dhcp` enables the local DHCPv6 server. |

**Catch:** the `no` form disables the subnet's address-configuration mode; it does not select SLAAC as a fallback mode.

### `ipv6 subnet number` — changes settings

Assigns the subnet ID used to determine the prefix advertised for the segment.

**RCI** `/rci/ipv6/subnet/number`

**Arguments:**

| Argument | Notes |
|---|---|
| `number` | Subnet ID used in the advertised prefix. |

**Catch:** the ID must be unique across subnets, so it is not merely a number local to the current subnet context.

### `ipv6 subnet prefix delegate` — changes settings

Sets the delegated prefix length for the current IPv6 subnet.

**RCI** `/rci/ipv6/subnet/prefix/delegate`

**Arguments:**

| Argument | Notes |
|---|---|
| `delegate` | Delegated length, which must be less than the subnet's prefix length. |

**Catch:** validity depends on the separately configured subnet prefix length; a value that is numerically valid can still fail when it is not smaller than that length.

### `ipv6 subnet prefix length` — changes settings

Sets the current IPv6 subnet's prefix length, whose documented default is /64.

**RCI** `/rci/ipv6/subnet/prefix/length`

**Arguments:**

| Argument | Notes |
|---|---|
| `length` | Prefix length from /32 through /64. |

**Catch:** the `no` form restores /64 rather than disabling the subnet prefix configuration.
