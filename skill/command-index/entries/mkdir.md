# `mkdir` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `mkdir` — read-only

Creates a directory at the supplied path.

**RCI** `/rci/mkdir`

**Arguments:**

| Argument | Notes |
|---|---|
| `directory` | Destination directory path. |

**Catch:** NONE
