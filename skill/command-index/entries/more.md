# `more` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `more` — read-only

Prints a text file one line at a time.

**RCI** `/rci/more`

**Arguments:**

| Argument | Notes |
|---|---|
| `filename` | Full file path or an alias. |

**Catch:** NONE
