# `eula` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `eula accept` — read-only

Records acceptance of the EULA the system currently offers.

**RCI** `/rci/eula/accept`

**Catch:** Until the agreement is accepted, the configurator permits only read-only commands.
