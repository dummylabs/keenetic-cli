# `igmp-snooping` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `igmp-snooping disable` — changes settings

Turns off IGMP snooping.

**RCI** `/rci/igmp-snooping/disable`

**Catch:** the command is available only when the device is operating in Client, Repeater, or AP mode.
