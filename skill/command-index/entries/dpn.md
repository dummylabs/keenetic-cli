# `dpn` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `dpn accept` — read-only

Records acceptance of the DPN the system currently offers.

**RCI** `/rci/dpn/accept`

**Catch:** Before the notice is accepted, the configurator refuses commands other than read-only operations.
