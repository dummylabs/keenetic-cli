# `isolate-private` commands

Derived from the Keenetic KN-1011 CLI manual (OS 5.0). Wording is original; nothing here has been run against a router.

### `isolate-private` — changes settings

Controls whether interfaces marked private may exchange data with one another.

**RCI** `/rci/isolate-private`

**Catch:** the feature is enabled by default, so private-interface isolation is active unless explicitly cancelled.
